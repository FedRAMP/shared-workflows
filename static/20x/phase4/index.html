The latest on FedRAMP 20x Phase 4¶

This site is under development. :)

It shouldn't be public, but if you've stumbled across it, please stand by.

FedRAMP 20x Phase 4 is a 9-month pilot and development phase intended to transition all new commercial FedRAMP Certifications to FedRAMP 20x. It began on October 1, 2026 (FY27 Q1) and will run through June 30, 2027 (FY27 Q3).

At the completion of Phase 4, FedRAMP 20x will move into Phase 5 which will focus on creating a transition path for legacy Rev5 Certifications.

Industry Facing Initiatives¶

20x Class D Pilot¶

Developing and testing assurance requirements for FedRAMP 20x Class D (High). The 20x Class D Pilot will start in January 2027 and is open to participants with a FedRAMP 20x Class C Certification who are selected by FedRAMP based on qualifications shown in a special application.

20x Class D Pilot

20x Self-Hosted Rules¶

Collaborating with industry to identify effective existing commercial certifications and requirements that can be reused for self-hosted or hybrid-hosted services as an alternative to a traditional control-based approach for managing physical datacenter infrastructure.

20x Self-Hosted

Rev5 Program Closeout¶

New FedRAMP Rev5 Certification won't be available after June 11, 2027, so FedRAMP will initiate a special project in early 2027 to ensure that any cloud service offering that is in process with an agency sponsor for Rev5 can receive a FedRAMP Certification before the pipeline officially closes.

Rev5 Program Closeout

Government Facing Initiatives¶

Agency Cloud Use Pilot¶

Developing and testing the new FedRAMP Board-approved Cloud Authorization Management Framework and Cloud Security Authorization process with agencies - for both FedRAMP Rev5 and 20x.

Agency Cloud Use Pilot

A-130 Class G Pilot¶

Working with agencies to implement government-specific expectations for agency-provided cloud service offerings created by government, for government.

A-130 Class G Pilot
